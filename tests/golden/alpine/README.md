# golden-alpine

This lab project was generated by `simp-vmgen 0.3.2`.

`vmgen.toml` is the source of truth. The generated `Makefile` is a thin wrapper
around `simp-vmgen`; do not edit it by hand. After changing `vmgen.toml`, run:

```sh
make regen          # update generated files
make regen-check    # report drift without writing
```

`make regen` only updates the generated files. After changing runtime settings
(users, packages, mounts, VM resources or kernel options), run `make build` to
refresh the seed/overlay, or the relevant `make kernel-*` target. `run` refuses
artifacts that were built from an older configuration.

`vmgen.lock` pins the base image URL and checksum. Generated file hashes are
tracked in `.simp-vmgen/generated.json`; `regen` preserves local edits unless
you pass `--force`.

The default login account is selected by `ssh.user`. Root SSH login can be
disabled with `ssh.permit_root_login = false`; in that case `ssh.user` must be a
non-root account.

Change them for shared or non-local hosts.

## Commands

```sh
make build       # download/cache the image, create overlay and seed
make up          # build if needed, start and wait for readiness
make restart     # stop, start and wait for readiness
make run         # start the VM in the background
make wait        # wait for the guest readiness marker
make tty         # interactive: SSH into the guest
make guest CMD='...'   # run one command in the guest
make lab CMD='...'     # run one command in /work
make show        # show the resolved configuration
make diagnose    # check host dependencies
make serial      # interactive: attach to the serial console
make console     # interactive: attach to the QEMU monitor
make status
make log         # print recent serial log lines
make log-follow  # interactive: follow the serial log
make stop
make clean
```

`simp-vmgen show --json` and `simp-vmgen status --json` are available for
scripts. `status --check` exits 3 when the VM is stopped.

Build, download and provisioning output is streamed and appended to
`.simp-vmgen/logs/`. Kernel builds can take a long time.

## Non-interactive / agent usage

Safe for scripts and agents: `make diagnose`, `make show`, `make build`,
`make run`, `make wait`, `make status`, `make guest CMD=...`, `make log`,
`make stop`, `make clean`.

These attach to a terminal and block: `make tty`, `make ssh`, `make serial`,
`make console`, `make log-follow`, `make run-fg`, and
`simp-vmgen gdb --connect`.

Use `simp-vmgen guest -- 'command'` for one shell string, or
`simp-vmgen guest -- word ...` for argv. `simp-vmgen guest --workdir DIR -- ...`
runs the command in a guest directory; add `--timeout SECONDS` for commands
that may hang.

Kernel projects also provide `make kernel-fetch`, `make kernel-config`,
`make kernel-build`, `make kernel-rootfs`, `make kernel-initramfs`,
`make kernel-status` and `make kernel-clean`.
Artifact-mode projects skip the source build and boot the configured
`kernel.artifact` instead.

## Requirements

Install `simp-vmgen` 0.3.2 on the host:

```sh
uv tool install "git+https://github.com/aurora0x27/simp-vmgen@v0.3.2"
```

Then run `simp-vmgen diagnose` from this directory to check host dependencies.
